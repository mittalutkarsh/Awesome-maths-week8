The plan

The same four steps work on every problem this week except Problem 21, which is arithmetic: default back to a, ar, ar², …; divide to a power of r; build what you need; check for a hidden ± and list the rungs.

  1. Default back to a, ar, ar², … Put each known term on its rung. (A repeating block is one rung.)
  2. Divide two rungs to get the power of r you know. Don't solve for r unless you must.
  3. Build what you need from that power: a term, or a sum from a, r and the next rung r^(n+1). Forever with −1 < r < 1: the next rung → 0.
  4. Check: did an even power hide a ±? List the first few rungs.

Arithmetic or geometric?

The teacher opened by lining up last week against this week. Arithmetic sequences are defined by addition: the same difference each time. Geometric sequences are defined by multiplication: the same ratio each time. Repeated addition is multiplication, and repeated multiplication is a power, so the formulas look alike:

arithmeticgeometric
step+ d× r
term ka + (k − 1)da · r^(k−1)
middle of threeaverage: (x + y) ÷ 2geometric mean: √(xy)
example3, 5, 74, 12, 36

The middles match the pattern: 5 = (3 + 7) ÷ 2, and 12 = √(4 × 36) because 4 × 36 = 144 = 12². The one big difference shows up in sums: arithmetic ends pair up, geometric ends don't, so geometric sums need the “next rung” formula instead.

How grading works

Each problem is split into steps, one value per step. He writes his method in the lined box and types the answer (a number, a fraction like 3/16, a power like 3^7, a root like 111√3, two values like ±160, a letter, or “first term, ratio” for a sequence he builds), then presses Check step (Enter in the answer box, Ctrl+Enter in the working box).

A wrong answer gets a nudge, and the nudges get more specific each time. After three misses he gets one final attempt; if that misses too, the step's answer is handed over and he does the next step himself. Hint for this step opens a hint without using a try (it's noted in My steps). Submit question reports how each step went and opens the verified answer and a step-by-step picture story once every step is closed. Show worked answer asks twice if some steps haven't been tried.

Sequences he builds himself (Problems 16 and 17) are checked by listing the rungs, so any correct answer passes.

Nothing is saved when the tab closes: progress and ink start fresh each visit.

The teaching pen

Press P (or the ✎ button) to write on any page. Four inks, three nibs, a highlighter, straight lines, boxes and an eraser; hold Shift for a straight stroke. Stylus only ignores your palm. On the notes page the ink stays with the text as you scroll and a finger scrolls; on the workbenches the ink stays with each problem. PNG saves the ink only, not the page underneath.
